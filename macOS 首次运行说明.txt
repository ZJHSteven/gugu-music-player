咕咕点歌台 · macOS 首次运行说明
================================

一、怎么启动
------------
双击「启动.command」。

如果提示「无法打开，因为无法验证开发者」：
  1. 在「启动.command」上点右键
  2. 选「打开」
  3. 弹窗里再点一次「打开」

只需要做一次，以后双击就能直接启动。

二、如果双击没反应 / 提示权限不足
--------------------------------
打开「终端」App，输入下面两行（把路径换成你解压的位置）：

  cd ~/Downloads/gugu-music-player
  chmod +x 启动.command runtime/darwin-*/node runtime/darwin-*/cloudflared
  ./启动.command

三、如果还是被系统拦住
----------------------
在终端里执行（把路径换成你的文件夹）：

  xattr -dr com.apple.quarantine ~/Downloads/gugu-music-player

这是 macOS 对「从网上下载的程序」的隔离标记，去掉之后就不会再拦。

四、运行起来之后
----------------
窗口里会显示一个「扩展安装地址」，并且已自动复制到剪贴板。
打开 Owlbear Rodeo → 左下角三个点 → Extension → 右上角加号 → 粘贴 → 确认。

这个窗口要一直开着。关掉或重启后地址会变，需要重新装一次扩展。

五、你的 Mac 是哪种芯片
----------------------
点左上角苹果标志 →「关于本机」：
  芯片写着 Apple M1/M2/M3/M4  → 用 runtime/darwin-arm64（包里已含）
  芯片写着 Intel Core i5/i7   → 用 runtime/darwin-x64（包里已含）

两个都在包里，脚本会自动选，不用你管。
